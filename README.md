READ ME
A third-person puzzle-exploration game where you navigate around a large manor trying to escape by finding the key to the exit door, avoiding any obstacles or enemies your actions may cause.

## Controls

| Key | Action |
|-----|--------|
| **W A S D** | Move |
| **Mouse** | Look around |
| **Shift** | Sprint |
| **E** | Interact |
| **F** | Use the selected inventory item |
| **Q** | Drop the selected inventory item |

## How to Play

- Hold **Shift** while moving to sprint.
- Walk up to objects and press **E** to interact with them when prompted by the dialogue box (open doors, pick things up, interact with objects).
- Items you collect go into your inventory, which has a size of 1. Press **F** to use the selected item, when prompted in the dialogue box.
- Press **Q** to drop the selected item if you no longer need it.

## Requirements

- [Platform, e.g. Windows 10/11]
- [Unreal Engine 5.7]

## Installation

1. Download the zip folder.
2. Extract the folder.
3. Run `Game_205_CK_MF.exe`.
